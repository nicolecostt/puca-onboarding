# Plano: app para Mac (#158)

Objetivo: o jurado roda **um comando no terminal**, o Orbis abre no Mac e a sessão com a Puca funciona com voz,
usando o servidor no Fly (`https://orbis-puca.fly.dev`).

Base: `PRODUCT.md` §13.3 · decisão 0004 · `docs/stack.md` §3. Fora do escopo: navegador da Puca (#123), login do
Supabase no app (o Fly responde sem token por enquanto).

Branch: `feat/158-app-mac`. Passos marcados com **[manual]** precisam de alguém na frente do Mac.

## Tarefa 1 — Contrato do `window.orbis`

- Pela skill `contrato`, registrar em `docs/contratos.md` a ponte mínima: `window.orbis = { versao: string }`, só no
  app. Sem `window.orbis`, o front segue como no navegador. A parte `navegador` entra com a #123.
- Registrar `VITE_API_URL` (base das chamadas ao servidor; vazio = relativo, como no `npm run dev`).

## Tarefa 2 — Front chama o servidor do Fly quando roda no app

- `src/voice/api.ts` (novo): `apiUrl(path)` junta `import.meta.env.VITE_API_URL` com o caminho; caminho absoluto
  (`https://…`) passa direto.
- `src/voice/agent-voice.ts`: as 5 chamadas `/api/...` passam por `apiUrl`.
- `src/voice/pcm-player.ts`: o `audio_url` (vem do servidor como `/api/tts/<id>`) passa por `apiUrl`.
- Teste em `src/voice/api.test.ts`. O PR avisa quem cuida da voz.

## Tarefa 3 — `desktop/` (Electron)

- Dependências de desenvolvimento: `electron`, `electron-builder`, `esbuild` (já aprovadas na 0004).
- `desktop/main.ts`:
  - `protocol.registerSchemesAsPrivileged` para `app` (`standard`, `secure`, `supportFetchAPI`, `corsEnabled`,
    `stream`) antes do `ready`: sem isso, microfone, `localStorage` e CORS do Fly não funcionam;
  - `protocol.handle("app")` serve os arquivos de `dist/`, sem deixar sair da pasta;
  - janela abre `app://orbis/index.html`; com `ORBIS_DEV_URL`, abre o Vite (`http://localhost:5173`);
  - `contextIsolation`, `sandbox`, sem `nodeIntegration`; `setWindowOpenHandler` abre link externo no navegador
    da pessoa; `will-navigate` só dentro do Orbis;
  - microfone: `systemPreferences.askForMediaAccess("microphone")`; `setPermissionRequestHandler` libera `media` só
    para a origem do Orbis.
- `desktop/preload.ts`: `contextBridge.exposeInMainWorld("orbis", { versao })`.
- `tsconfig.json` passa a incluir `desktop`; `.gitignore` ganha `dist-desktop/` e `release/`.
- Scripts: `build:desktop` (esbuild), `dev:app` (Electron apontando para o Vite).

**[manual] Teste em dev** (detalhes no fim).

## Tarefa 4 — Empacotar

- `desktop/electron-builder.yml`: `appId: com.orbis.app`, `productName: Orbis`, `mac.target: zip` para `arm64` e
  `x64`, `artifactName: Orbis-mac-${arch}.${ext}`, `identity: null`, `extendInfo.NSMicrophoneUsageDescription`,
  `afterPack` com `codesign --force --deep --sign -`.
- `build:app`: `vite build` com `VITE_API_URL=https://orbis-puca.fly.dev` + `build:desktop` + `electron-builder` +
  um `.sha256` para cada `.zip` em `release/`.
- Conferência automática: `codesign --verify` no `.app` gerado.

**[manual] Abrir o app empacotado** (detalhes no fim).

## Tarefa 5 — Instalador e release

- `scripts/instalar.sh` (§3.4): escolhe o `.zip` por `uname -m`, baixa do último Release, confere o `sha256`, instala
  em `~/Applications/Orbis.app` com `ditto`, tira a quarentena e abre. `--desinstalar` apaga o app e os dados locais.
- `.github/workflows/release.yml`: em tag `v*`, num `macos-14`, roda `npm ci` e `npm run build:app` e cria o Release
  com os dois `.zip` e os `.sha256`.
- README: seção "App para Mac" com o comando.

## Passos manuais, com instruções

### A. Teste em dev (depois da Tarefa 3)

1. Terminal 1: `npm run dev` (deixe aberto).
2. Terminal 2: `npm run dev:app`. Abre uma janela "Orbis" com a tela inicial.
3. Na primeira vez, o macOS pergunta se o Electron pode usar o microfone: clique em **Permitir**.
   - Se clicou em "Não permitir": Ajustes do Sistema → Privacidade e Segurança → Microfone → ligue "Electron".
4. Siga até a sessão, ligue a call e fale. Confira: a Puca responde com voz e o quadro anda.
5. Me diga o que viu (ou mande print de algo estranho).

### B. Abrir o app empacotado (depois da Tarefa 4)

1. Eu rodo `npm run build:app`; os arquivos ficam em `release/`.
2. Abra `release/mac-arm64/Orbis.app` com duplo clique.
3. O macOS pede o microfone para **Orbis**: **Permitir**.
4. Faça a sessão com voz, como em A. Agora o servidor é o do Fly (sem `npm run dev:server`).
5. Se aparecer "Orbis está danificado" ou "não pode ser aberto", me avise com o texto exato.

### C. Push, PR, merge e tag

- Eu peço o ok antes de cada um. O merge na `main` precisa da revisão do time (skill `revisar`).
- Depois do merge, com o seu ok, eu crio a tag: `git tag v0.1.0 && git push origin v0.1.0`.
- Acompanhe em GitHub → Actions → "Release" (~10 min). No fim, o Release `v0.1.0` tem 4 arquivos.

### D. Teste em outro Mac (#39)

Num Mac de outra pessoa do time (ou de alguém de fora), sem clonar nada:

1. Abrir o Terminal e colar:
   `curl -fsSL https://raw.githubusercontent.com/nicolecostt/puca-onboarding/main/scripts/instalar.sh | bash`
2. Esperar baixar (~100 MB). O Orbis abre sozinho.
3. Permitir o microfone e fazer a sessão com voz.
4. Anotar: o modelo do Mac (Apple Silicon ou Intel), a versão do macOS e qualquer erro (print do Terminal).
5. Para remover depois: `curl -fsSL https://raw.githubusercontent.com/nicolecostt/puca-onboarding/main/scripts/instalar.sh | bash -s -- --desinstalar`
